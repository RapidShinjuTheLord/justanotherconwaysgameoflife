# justanotherconwaysgameoflife
I just made conways game of life for practice with python 2D arrays and algorithmic implementation.

The controls are:

* Space to clear
* Any key to timestep

Hopefully the variable naming and the if statements are clear enough to take and remix for your own purposes, feel free to use code without permission, although credit would be nice.
